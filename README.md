# Sanad Biswas, Ph.D.

**Assistant Professor of Data Science**  
Sam Houston State University

I work at the intersection of **machine learning, statistical modeling, explainable and responsible AI, generative AI, predictive modeling, and MLOps**. My research focuses on building accurate, interpretable, reproducible, and practically useful data science systems.

## Selected Research & Projects

### [CKD Temporal Screening](https://github.com/sanadbiswas/ckd-temporal-screening)
Temporal validation of a non-laboratory machine learning framework for chronic kidney disease screening in U.S. adults.

### [Feature Significance and Explainability in Neural Networks](https://github.com/sanadbiswas/Feature-Significance-and-Explainability-in-Neural-Network)
Research on feature significance, statistical testing, interpretation, and explainability in modern machine learning models.

### [Machine Learning](https://github.com/sanadbiswas/Machine_Learning)
Machine learning experiments, examples, and instructional materials covering applied modeling workflows.
